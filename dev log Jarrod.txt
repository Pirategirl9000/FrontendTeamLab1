JSON File

I was in charge of creating the .json file and fetching the data from the .json file. I went with a structure of each product having a unique productID followed by the Product Name, Price, Seller, Category, Description and Availability. These would all be relevant when displaying the products on tiles, etc...

For fetching that data from the .json file I decided on using a UseEffect for pulling in the products.
It Preserves the raw dataset, keeping the full products list intact. Also ensures that you do not lose any items when filtering, allowing users to clear or change their search without re-fetching from the file. Doing it this way also separates lifecycles for better performance ensuring that the filtering logic only runs when the search text or selected category actually changes, rather than executing on every single component re-render.
