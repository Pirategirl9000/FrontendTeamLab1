Interface Planning and Design

As the web designer for GenStore, I was responsible for planning the visual architecture, establishing the responsive layout system, building the persistent shell 
components (Header and Footer), and styling the application for an authentic e-commerce feel.

I started with gettign a better uderstanding of exactly how the default css files worked to then continue using them throught the program.

I began by drafting the Interface Sketch (InterfaceSketch.png) to establish the application layout, featuring a sticky header for branding and social channels, 
revised the body componets, and an anchored footer.

Header Component & Social Integration:
In Header.jsx and Header.css, I created a responsive header utilizing Flexbox to position the store title and the SocialBar. The social icons are structured with CSS Grid, 
featuring a 4-column layout on desktop that dynamically reorganizes into a 2x2 grid on mobile viewports (<= 640px). I scaled the static logo graphics from 20px up to 32px 
for improved clarity, and added smooth background hover transitions.

Footer Component & Dynamic Navigation:
In Footer.jsx and Footer.css, I built out the navigation links (Support, FAQ, Report, Become a seller, and Orders) and copyright banner. I configured .footerLinks with 
flex-wrap: wrap so links wrap cleanly on mobile screens without horizontal overflow, and added hover transitions.

Global E-Commerce Theming & Palette:
In index.css, I designed the global color palette using CSS variables (--bg, --text, --accent, --border, --social-bg) supporting both light and dark modes via @media 
(prefers-color-scheme: dark) for strong visual contrast and accessibility.

Form Polish, Container Spacing, and Product Grid Alignment:
In App.css, I added flush padding (1rem) across .listingSection, .filterForm, and .products to eliminate edge collisions. I styled all form fields with thematic 
backgrounds, rounded borders, and custom glowing focus states (box-shadow). On .listingSubmit, I added text-transform: capitalize for clean button styling. In ProductGrid.css,
I added mobile centering for single-column displays (<= 544px).

Debugging & Problem Resolutions:
1. Sticky Footer Viewport Floating: Resolved floating footer on short/empty content pages by setting #root to min-height: 100svh flex column and footer to margin-top: auto.
2. Social Bar Mobile Collision: Resolved 4-column overflow on small viewports (<= 640px) by reorganizing .socialBar into a 2x2 CSS Grid with scaled 1.5rem icons.
3. Form Edge Clipping & Focus Feedback: Resolved input edge collisions and poor active states by adding horizontal container padding and glowing focus rings.
