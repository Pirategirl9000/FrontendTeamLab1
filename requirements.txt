Part 3 — Development Process
Teams must follow our established software development process rather than immediately beginning to code.  Documentation is important at this point and should be complete and professional.
Step 1 — Document and Divide & Conquer
Identify the applications main features, divide the work into smaller tasks, sketch the user interface, and determine which React components are needed.
Create a component hierarchy showing parent child relationships and where shared state will live.
Step 2 — Design the Algorithms
Write pseudocode for adding, editing, deleting, searching, and filtering records.
Explain how the application will update arrays without directly mutating React state.
Step 3 — Build the Application
Create a Vite project, develop the components, load starter JSON data, implement state management, and connect the components through props and callback functions.
Create your new GitHub repository so everyone can contribute their code. 
Build one working feature at a time.
Step 4 — Test and Improve
Test each CRUD operation, empty inputs, search results, filters, and the behavior when no records match.
Fix errors and verify that the browser console contains no unresolved application errors.


Part 4 — Team Responsibilities
Each team member must make meaningful contributions to both development and testing.
Every team member must be able to explain at least one component, one state variable, and one event handling function during the demonstration.
Each team must implement at least one additional feature that makes its application more interesting.
Examples include a favorites system, sorting controls, a progress indicator, summary statistics, a random recommendation, or a custom status workflow.
The feature must involve React state or meaningful JavaScript logic, not simply additional styling.


Part 5 — Testing Documentation
Teams must submit evidence of testing. (This will be part of your class demonstration)
Test	Expected result
Add a valid record	New record appears
Submit an empty required field	Validation prevents submission
Edit an existing record	Updated information appears
Delete a record	Record disappears
Search for a known record	Matching records display
Search for nonexistent text	Empty state message appears
Select a filter	Only appropriate records display
Reset search and filter	All current records display
Students must record actual results and document at least two problems they encountered and how they resolved them.
