## Features
* Viewing of product listings and creating new listings
* Text and category based filtering
    * Text based filtering can use price, description, product name, and seller to filter by with support for combined queries using '&' delimiter

## Installation
* Download the zip file and extract all
* Navigate to folder
    * Ensure you have npm installed and in your system path
* Run `npm install` to install the dependencies
* Run `npm run dev` and navigate to http://localhost:5173/
